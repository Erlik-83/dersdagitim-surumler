# Ders Dağıtım — kurulum dosyaları

Bu sayfada yalnızca Ders Dağıtım uygulamasının kurulum dosyaları bulunur.
Uygulama, yöneticinin verdiği **lisans dosyası** olmadan açılmaz.

**İndirmek için:** sağdaki **Releases** bölümünden en son sürümü açın.

| Bilgisayar | Dosya | Kurulum |
|---|---|---|
| Windows 10 / 11 | `DersDagitim-Kurulum-<sürüm>.exe` | Çift tıklayın. "Windows bilgisayarınızı korudu" uyarısında **Ek bilgi → Yine de çalıştır**. |
| macOS (Apple M1 ve sonrası) | `DersDagitim-<sürüm>.dmg` | Açın, simgeyi **Uygulamalar**'a sürükleyin. İlk açılışta simgeye **sağ tıklayıp Aç**. |

Güncellerken yeni sürümü eskisinin üzerine kurun; okul verileriniz silinmez.
